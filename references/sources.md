# 참고한 자료

- [Anthropic: Define success criteria and build evaluations](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) — ‘좋은 글’을 막연히 요청하기보다 성공 기준과 확인할 사례를 나누는 데 참고했다.
- [Anthropic: Skill authoring best practices](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices) — 사용 중 관찰한 실패를 반영하고 다시 실행하는 스킬 개선에 참고했다.

이 문서들이 이 스킬의 효과나 개인 미감을 입증한 것은 아니다. 단어·접속사·문장 길이의 보편 합격선을 제시하는 근거로 쓰지 않는다.

- [NVIDIA Nemotron Personas Korea](https://huggingface.co/datasets/nvidia/Nemotron-Personas-Korea) — 독자 선정에 쓰는 실제 합성 인물 데이터. uuid·revision·원문 필드와 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 출처를 유지한다.
- [저자 워크숍 상세소개](https://mproject2017.tistory.com/entry/자소서-리뷰-워크숍-퓰리처상에-빛나는-저자워크숍-상세소개) — 요약·좋았던 점·개선 제안·저자의 질문 순서를 합성 독자 대화에 맞춰 참고했다. 개인 블로그의 진행 안내이며, 효과를 입증한 연구나 이 스킬의 공식 평가 기준으로 소개하지 않는다.
