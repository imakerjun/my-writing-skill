# 코드가 세는 것

- 글자 수: Python 문자열의 Unicode 코드 포인트 수. 공백 포함/제외를 구분한다.
- 어절 수: 공백으로 나눈 단위. 형태소나 영어 단어 수가 아니다.
- 문장: 문단과 구두점을 기준으로 나눈 근사치. 인용·약어를 직접 확인한다.
- 연결 표현: 미리 나열한 표현이 문장 앞에 나온 경우만 센다. 한국어의 모든 접속 표현·연결 어미 수가 아니다.
- 반복: 같은 표면형의 반복. 형태소를 정규화하지 않는다.

긴 문장·접속 표현은 다시 읽을 위치를 찾는 데 쓴다. 횟수를 줄였다고 좋은 글이 됐다고 판정하지 않는다. 문장 분리나 인과·화자의 보존 여부는 LLM과 사람이 문맥에서 확인한다.
