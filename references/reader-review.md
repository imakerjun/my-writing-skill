# 이번 글을 읽을 사람에게 물어보세요

같이 오래 고친 글은 처음 읽는 사람에게 어디가 어려울지 놓치기 쉬워요. 누구에게 읽힐 글인지 정하고, 어떤 뜻으로 읽었는지 한번 물어보세요. 글이나 장이 달라지면 독자도 다시 고를 수 있습니다.

## 독자가 이미 아는 것부터 적어봅니다

[프로필 틀](../templates/reader-profile.json)에 이 사람이 왜 이 글을 읽는지, 이미 아는 것은 무엇인지 적어주세요. 나이나 직업만으로 취향과 반응까지 정하지는 않습니다.

실제 독자에게 부탁해도 좋고, LLM에 독자 역할을 맡겨볼 수도 있어요. 가정한 역할은 `role_assumption`으로 표시합니다. LLM의 답을 실제 사람의 리뷰처럼 소개하지 않도록 기록에도 구분해두세요.

**Nemotron Personas Korea를 쓴다면** [NVIDIA 공식 데이터셋](https://huggingface.co/datasets/nvidia/Nemotron-Personas-Korea)의 실제 행을 골라 uuid와 사용한 필드를 남겨주세요. 제공된 캐시와 도구, 사용 지침을 먼저 확인합니다. 데이터가 이미 있는지 확인하기 전에 다시 내려받지 마세요. 없다면 다운로드 크기와 저장 위치를 사용자에게 알리고 확인받습니다. 데이터나 도구가 없을 때는 연결 방법을 안내하고, 임의로 만든 인물을 Nemotron 표본으로 대신하지 않습니다. 데이터셋 자체는 이 저장소에 넣지 않아요.

## 먼저 글만 읽혀보세요

독자 역할을 맡은 LLM에는 인물 설정과 읽을 문단을 먼저 주세요. 저자가 전하고 싶었던 뜻이나 기대하는 반응을 미리 알려주면 그 답을 따라갈 수 있어요.

- 어떤 뜻으로 읽었나요?
- 멈추거나 다시 읽은 곳이 있다면 어느 구절인가요?
- 읽고 나서 궁금한 점은 무엇인가요? 직접 해볼 만한 일이 보이나요?

어느 버전의 문단을 누구에게 읽혔는지, 어떤 구절에 어떤 반응이 나왔는지 함께 남겨주세요. ‘모두 좋아했다’고 요약하면 정작 고칠 곳을 찾기 어려워요. 원문 구절을 짚지 않은 감상은 추가로 확인해볼 내용으로 남겨둡니다.

## 내 글에 반영할 리뷰를 고릅니다

여러 리뷰가 오면 중요한 것 하나부터 읽어보세요. 이 리뷰를 반영할지 **0점=이건 아니다 / 1점=애매하다 / 2점=좋다**로 판단하고, 이유를 한 줄 남길 수 있어요. 여기서 매기는 점수는 ‘이 리뷰를 반영하고 싶은가’에 대한 점수입니다. 원고에 준 점수와 구분해두세요. AI가 내 선택을 대신 정하지는 않습니다.

편집 역할에는 원고와 이번 글의 의도, 반영하기로 한 리뷰를 주세요. 후보 하나를 받은 뒤 같은 독자 설정으로 다시 읽혀봅니다. 처음과 같이 이해한 뜻과 걸린 구절을 물어보고, 내 의도에 맞게 바뀌었는지 살펴보세요.

LLM 독자 리뷰는 실제 독자에게 물어보기 전에 예상 질문을 찾는 데 쓸 수 있어요. 여러 합성 독자가 비슷하게 답하더라도 실제 사람들의 선호율이나 대표성으로 해석하지 않습니다. 실제 독자에게도 확인해볼 질문으로 남겨주세요. 외부 연락이나 설문 발송이 필요하다면 별도로 허락을 받아야 합니다.
