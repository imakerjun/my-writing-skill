# 어디서 왔나

메이커준(임동준)이 긴 글을 쓰며 만든 ‘사람냄새’ v2.3에서 시작했습니다. 처음에는 본인의 원고와 말투에 맞춰 쓰던 도구였어요.

공개판에서는 적용·보류·보존, 인과와 화자 보호, 지침과 eval 분리를 유지하면서 특정 책·개인 폴더·다른 사내 스킬에 대한 의존을 제거했다. 문장 신호 추출기와 0·1·2점 기록 도구를 함께 제공한다. 원본과 공개판을 같은 버전이라고 하지 않는다.

- `scripts/analyze.py`: 별도 `writing-signal-review`의 정량 신호 추출기를 재사용했다.
- `scripts/grade.py`: 원본 사람냄새 eval 채점기를 재사용했다.
- `SKILL.md`: 원본 지침을 일반 사용자가 자기 문체와 기준을 제공할 수 있게 공개용으로 편집했다.
- 공개 eval: 새 가상 예문 3개. 기존 원고·저자 피드백·페르소나 원답·내부 링크·과거 Git 이력은 포함하지 않는다.

과거 원본에서 특정 테스트가 통과했다는 결과를 새 공개판의 성능으로 옮기지 않는다. 이 저장소의 고정 프로그램 테스트와 모델 실행 결과는 구별한다.

2026-10-22 공개판 v0.2.0부터 이름을 My Writing Skill로 바꾸고, 내 문장·이유·적용 문맥을 개인 기준으로 축적하는 흐름을 추가했다. v0.1.0 실행 기록과 해시는 당시 상태로 보존한다.

2026-10-22 공개판 v0.3.0은 발표의 세 가지 협업을 따라 직접 해보는 흐름으로 재구성했다. 장별 브리프와 독자 선정, 점수·이유에서 지침 제안과 확인, 독립 설치 가능한 개인 스킬 생성기를 추가했다. 개인 점검어는 빈 목록에서 시작하며, 확인하지 않은 지침은 내보내지 않는다. v0.3.0 프로그램 검사 19건은 통과했고, 새 모델 실행 시도는 CLI 로그인 오류로 응답을 받지 못했다. 이전 모델 결과를 새 버전의 성능으로 옮기지 않는다.

2026-10-27 공개판 v0.4.0부터 세 스킬을 만드는 크리에이터로 바꿨습니다. 표현 점검, 핵심 다듬기, 독자 리뷰를 각각 생성하고 설치할 수 있어요. 기본 점검어와 실제 사용자 판단을 구분하고, Nemotron 실제 행 선정과 저자 워크숍 순서를 추가했습니다. 예전 통합 스킬 생성 방식은 유지합니다. 생성 성공·프로그램 검사·LLM의 독립 실행·실제 저자 평가를 나눠 기록합니다.
