# 이런 표현이 보이면 한번 더 읽어보세요

우테코 책의 ‘사람냄새’ v2.3에서 자주 살펴봤던 표현들이에요. 내 글에도 비슷한 문제가 있는지 보는 참고 목록으로 써주세요. 같은 말이라도 필요한 문장에서는 남겨야 합니다.

| 눈에 띈 표현 | 다시 읽으며 볼 것 |
|---|---|
| 리듬·매듭·여정·켜켜이·~하는 자리·~하는 순간 | 실제로 무엇을 가리키나요? 말은 그럴듯한데 장면이 잘 안 보이지는 않나요? |
| 빈 곳을 채운다·무게중심을 둔다·한 겹 더 | 누가 무엇을 했는지 직접 써보면 더 잘 읽힐까요? |
| 의미·가치·깊이를 만든다 | 무엇이 어떻게 달라졌는지 기록에서 확인할 수 있나요? |
| A도 B도 C도·같은 문장 구조의 반복 | 서로 다른 이야기를 하나요, 같은 설명을 되풀이하나요? |
| 오롯이·고스란히·촘촘히·단단히 | 이 말을 빼면 뜻이 달라지나요? |
| 대시·가운뎃점 | 덧붙인 설명 때문에 읽다가 끊기나요? 필요한 나열이나 인용인가요? |
| ~인 셈이다·~기 마련이다 | 비슷한 마무리가 계속 나오나요? 한 번 썼다는 이유만으로 지우지는 마세요. |
| 겹말·겹친 관형절·어울리지 않는 명사와 동사 | 뜻을 유지하면서 더 평소 쓰는 말로 풀 수 있나요? |

인용문이나 이름 붙은 개념, 저자가 쓰기로 한 표현은 먼저 확인해주세요. 앞뒤를 잇는 말과 누가 한 말인지도 놓치지 않고요. 사람 냄새를 내려고 기록에 없는 감정이나 경험을 덧붙이지는 않습니다.
