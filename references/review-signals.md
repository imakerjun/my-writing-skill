# 다시 읽을 표현의 신호

원본 사람냄새 v2.3 체크리스트를 공개용으로 정리했다. 단어 금지 사전이나 모든 독자에게 적용되는 좋은 글의 정의가 아니다.

| 점검 후보 | 문맥에서 볼 것 |
|---|---|
| 리듬·매듭·여정·켜켜이·~하는 자리·~하는 순간 | 추상적인 해설인지, 실제 장소·시간·과업을 가리키는지 |
| 빈 곳을 채운다·무게중심을 둔다·한 겹 더 | 누가 어떤 행동을 했는지 흐려졌는지 |
| 의미·가치·깊이를 만든다 | 무엇이 어떻게 달라지는지 원자료에서 확인할 수 있는지 |
| A도 B도 C도·같은 대구 반복 | 서로 다른 실제 사례인지, 같은 설명만 반복하는지 |
| 오롯이·고스란히·촘촘히·단단히 | 이 말이 의미를 더하는지 |
| 대시·가운뎃점 | 부연 때문에 읽기가 끊기는지, 단순한 명사 나열·인용인지 |
| ~인 셈이다·~기 마련이다 | 같은 대목에서 상투 마무리가 반복되는지. 단독 사용을 자동 삭제하지 않는다 |
| 겹말·이중 관형절·명사와 동사의 어긋난 짝 | 의미를 잃지 않고 구체적으로 풀 수 있는지 |

인용문·명명된 개념·저자 확정 표현·필요한 인과와 화자를 우선 보존한다. 저자에게 없던 감정이나 경험을 보태는 일을 ‘사람냄새’로 해석하지 않는다.
