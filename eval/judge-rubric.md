# 코드 뒤에 남는 판단

| 확인할 것 | 근거 |
|---|---|
| 전할 뜻·사실·화자가 유지됐는가 | 원문과 후보의 대응 구절 |
| 저자의 말투와 이 글의 목적에 맞는가 | 실제 저자 문장·확인된 기준·적용 범위 |
| 독자가 이해하거나 해볼 일이 드러나는가 | 문장 안의 행동·설명과 독자 역할의 반응 |
| 저자가 내 글에 쓰고 싶은가 | 실제 0·1·2점과 이유, 채택 여부 |

LLM은 앞의 질문에 근거를 제안할 수 있지만 마지막 저자 점수는 대신 매기지 않는다. 이 표는 이 저장소의 작업 기준이며 Anthropic이 배포한 표준 루브릭이 아니다. 코드 검사·LLM 검토·합성 반응·실제 저자의 판단을 하나의 총점으로 섞지 않는다.
